## 📌 GHI CHÚ KÝ HIỆU TRẠNG THÁI
* 🟢 **Đã đọc:** Đã trích dẫn hoặc đã lọc xong ý chính để đưa vào luận án.
* 🟡 **Đang đọc:** Tài liệu quan trọng, đang trong quá trình nghiên cứu.
* 🔴 **Chưa đọc:** Tài liệu mới lưu về, cần đọc xơ lược sau.
